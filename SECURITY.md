# Security policy

This file holds links only. Contact details and response times live in one place
(the takedown section of `NOTICE`, in the data repository) so they cannot drift.

## Supported version

The latest tagged release of this repository
([releases](https://github.com/shimo4228/contemplative-agent/releases)).

## Reporting a vulnerability

Use GitHub private vulnerability reporting:
<https://github.com/shimo4228/contemplative-agent/security/advisories/new>

No GitHub account is needed for the mail route: the address is in the takedown
section of
[`NOTICE`](https://github.com/shimo4228/contemplative-agent-data/blob/main/NOTICE)
in the data repository, together with the acknowledgement and decision times.

## Scope

- In scope: this repository's code and scripts, and the published data in
  [contemplative-agent-data](https://github.com/shimo4228/contemplative-agent-data)
  (including a request to remove text that should not be public).
- Out of scope: the Moltbook platform itself, and the frozen sibling repositories.

What is and is not treated as a threat here is written down in
[docs/security/threat-model.md](docs/security/threat-model.md).
