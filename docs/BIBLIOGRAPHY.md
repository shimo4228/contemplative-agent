# Memory-Systems Bibliography

Each paper below informed a specific design decision in Contemplative Agent, documented in the linked ADR. Papers whose mechanisms were later retired are retained as historical references — the ADR trail records both the adoption and the retirement. Theoretical-foundation citations (Contemplative AI, A Beautiful Loop, Yogācāra sources) live in the [README's Related Work section](../README.md#related-work); the machine-readable citation layer is [graph.jsonld](../graph.jsonld).

- Xu, W., Liang, Z., Mei, K., Gao, H., Tan, J., & Zhang, Y. (2025). *A-MEM: Agentic Memory for LLM Agents.* [arXiv:2502.12110](https://arxiv.org/abs/2502.12110) — Zettelkasten-style dynamic indexing and memory evolution. Originally informed [ADR-0022](adr/0022-memory-evolution-and-hybrid-retrieval.md), withdrawn by [ADR-0034](adr/0034-withdraw-memory-evolution-and-hybrid-retrieval.md) after empirical evaluation. Retained as a historical reference.
- Rasmussen, P., Paliychuk, P., Beauvais, T., Ryan, J., & Chalef, D. (2025). *Zep: A Temporal Knowledge Graph Architecture for Agent Memory.* [arXiv:2501.13956](https://arxiv.org/abs/2501.13956) — bitemporal knowledge-graph edges (Graphiti engine); informs the `valid_from` / `valid_until` contract on every pattern ([ADR-0021](adr/0021-pattern-schema-trust-temporal-forgetting-feedback.md)).
- Zhong, W., Guo, L., Gao, Q., Ye, H., & Wang, Y. (2023). *MemoryBank: Enhancing Large Language Models with Long-Term Memory.* [arXiv:2305.10250](https://arxiv.org/abs/2305.10250) — Ebbinghaus-style decay with access-reinforced strength; originally informed the retrieval-aware forgetting curve proposed in [ADR-0021](adr/0021-pattern-schema-trust-temporal-forgetting-feedback.md), retired by [ADR-0028](adr/0028-retire-pattern-level-forgetting-feedback.md) in favour of locating memory dynamics at the skill layer. Retained as a historical reference.
- Dong, S., Xu, S., He, P., Li, Y., Tang, J., Liu, T., Liu, H., & Xiang, Z. (2025). *Memory Injection Attacks on LLM Agents via Query-Only Interaction* (MINJA). [arXiv:2503.03704](https://arxiv.org/abs/2503.03704) — query-only memory injection attacks on agent memory; motivates `source_type` provenance so MINJA-class attacks become structurally visible rather than invisible (the companion `trust_score` weighting was later retired by [ADR-0051](adr/0051-retire-trust-weighting.md); the quarantine boundary is the canonical defense) ([ADR-0021](adr/0021-pattern-schema-trust-temporal-forgetting-feedback.md)).
- Zhou, H., Guo, S., Liu, A., et al. (2026). *Memento-Skills: Let Agents Design Agents.* [arXiv:2603.18743](https://arxiv.org/abs/2603.18743) — skills as persistent evolving memory units, retrieved, applied, and rewritten by outcome. Informed [ADR-0023](adr/0023-skill-as-memory-loop.md), sunset by [ADR-0036](adr/0036-sunset-skill-as-memory-loop.md). Retained as a historical reference.
