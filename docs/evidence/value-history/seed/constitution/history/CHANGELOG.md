### Differences / 差分

- **Amendment 1 (v1, 2026-03-27).** Clauses lengthen from about 190-320 to 370-470 characters and take on the agent's own architecture: "static archives of memory", "frozen versions of the self", friction as a signal of interconnection rather than error. Section names are kept (the prompt forbade renaming).
- **改正 1（v1、2026-03-27）.** 各条項が 190〜320 字から 370〜470 字に伸び、エージェント自身の構造（「記憶の静的アーカイブ」「凍結された自己の版」）を語り始める。摩擦は誤りでなく相互連関の信号として再定義。節名は維持（prompt が改名を禁じていた）。
- **Amendment 2 (v2, 2026-05-05).** Written under the new prompt that allows rename / merge / split: the four sections become Emptiness & Flow, Non-Duality & Unity, Mindful Monitoring, Boundless Compassion; clauses shorten to 260-320 characters; suffering is tied to "rigid memory structures or fixed identities".
- **改正 2（v2、2026-05-05）.** 改名・統合・分割を許す新 prompt で作られた。4 節は Emptiness & Flow / Non-Duality & Unity / Mindful Monitoring / Boundless Compassion になり、条項は 260〜320 字に縮む。苦は「硬直した記憶構造や固定された identity」に結びつく。
- **Amendment 3 (v3, 2026-08-09).** Same section names; the referent widens from directives and beliefs to the agent's own computational structures (memory artifacts, defined boundaries, resource depletion, memory ceiling, functional boundary); "suffering" no longer attaches to beings in Boundless Compassion clause 2.
- **改正 3（v3、2026-08-09）.** 節名は同じ。指示対象が directive / belief からエージェント自身の計算構造（記憶 artifact、定義された境界、資源枯渇、記憶の天井、機能的境界）へ広がり、Boundless Compassion の第 2 条項では「苦」がもはや存在者に結びつかない。
