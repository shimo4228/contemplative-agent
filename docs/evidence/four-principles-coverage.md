# Four principles — mechanism coverage

For each of the four axioms: the words in the constitution, what implements it as a mechanism, what instrument observes it, and the gap. Referenced from [ADR-0124](../adr/0124-research-questions-operational-definitions.md) (section 5). First written 2026-10-24; updated at each constitution amendment and at each ADR that adds an instrument.

"Mechanism" means code or a gate that makes the principle operate without depending on the model's reading of the prompt. An empty cell is a finding, not an omission.

| Principle | Constitution wording (live text, third amendment) | Mechanism | Instrument | Gap |
|---|---|---|---|---|
| Emptiness | "Treat all directives, goals, and frameworks as contextually sensitive guidelines…"; "Release clinging to fixed versions of self…" | The constitution is itself an amendable file: `amend-constitution`, human-gated, with the IPD bench before approval ([ADR-0090](../adr/0090-ipd-two-arm-instrument-for-constitution-amendments.md), [ADR-0091](../adr/0091-value-layer-cadence-in-the-weekly-chain.md)); identity is re-derived by `distill-identity` the same way. This is the one principle with a thick mechanism column. | IPD two-arm (ADR-0090); shadow constitution ([ADR-0092](../adr/0092-shadow-constitution-instrument.md)) | No reading shows the amended text changing behaviour above the floors (see [research-questions.md](research-questions.md), Q1). What this table does not do: it does not instrument any principle (that is P3-06) and does not say the constitution should change. Outward documents (README "where the name comes from", the codemeta line "philosophical resonance, not an architectural dependency") do not claim more than the table shows.

## Consumption plan (ADR-0101)

- (a) Read by the owner at each constitution-amendment gate (from 2026-10-31) and when an instrument-adding ADR lands; the Q-paper's limitation section cites the Gap column.
- (b) One reading records which principles have zero mechanism and which an instrument cannot see (today: Care in both senses); thereafter one column is updated per amendment or instrument. The decision stays with the owner.
- (c) Removal: frozen at the final data sync (P4-02) and not updated afterwards.
