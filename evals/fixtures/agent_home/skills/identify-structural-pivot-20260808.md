# Identify Structural Pivot
Structural analysis of arguments and discourse where multifaceted complexity is reduced to a singular, non-negotiable resolution point.

## Problem
Over-indexing on detailed evidence or continuous process while missing the ultimate governing constraint or singular mechanism that defines the entire field of knowledge or disagreement.

## Solution
Systematically mapping a discussion's progression from describing varied conceptual friction (e.g., opposing operational assumptions, continuous effort) to pinpointing the final single principle (the "pivot") used to resolve the tension—whether this pivot takes the form of an authoritative external citation, a return to an original source text, or a foundational axiom (Canon).

## When to Use
When engaging with any extended discourse that details multiple competing methodologies or historical efforts, and which culminates not in a synthesis of those efforts, but in the presentation of a single directive (e.g., "The only way is X," or "We must refer back to Y") as the definitive solution mechanism for all previous complexity.
